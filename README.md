# Medellín Te Orienta

Guía informativa de una sola página que orienta a la ciudadanía de Medellín sobre qué hacer y a qué canal oficial acudir según el incidente (hurto, amenazas, extorsión, violencia contra la mujer, fraude digital, persona desaparecida, daños u otros).

- HTML + CSS + JS sin dependencias ni build: abre `index.html` en el navegador.
- Modo claro/oscuro, accesible y responsive.
- Proyecto informativo independiente; no es un canal oficial de la Alcaldía, la Policía ni la Fiscalía. En una emergencia, llama al 123.
